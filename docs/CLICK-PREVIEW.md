# 点击波形定位试听

当前开发版本：Windows 0.3.4，Mac/Linux 0.4.2 preview。

## 操作

- 单击 Waveform 单元格中的位置，选中该素材并从相应比例处开始原生试听。例如 30 秒素材的 25% 对应约 7.5 秒。
- 已在播放同一文件时，再次点击可以重新定位。连续快速点击仅执行最后一次尚未处理的请求。
- 双击波形仍作为试听定位处理，不触发向工程插入素材；文件名等原生区域的操作继续交给 REAPER。
- Ctrl/Shift/Alt 等修饰键点击保留选择行为。按住鼠标不开始定位，进入拖拽时取消请求。
- 仅对已准备好的音频波形响应；XML、MIDI 等仍排除在波形/自动试听处理外。

缩略图代表整个源文件，所以点击时会把下方原生预览恢复为全长显示，再设置播放起点。试听使用原生通道，音量、输出路由、变速、循环等遵循 Media Explorer 设置；本功能不会改变工程的播放位置。

原生预览控件需要具备有效尺寸；如果折叠到无法定位，状态中的 `seek_error` 会提示展开预览区。定位精度受原生预览宽度的像素分辨率限制，不承诺采样点精度。

## 实现

三个后端共享 `preview_seek.hpp`，在主线程串行处理请求：等待鼠标释放和短暂稳定期，校验当前选择，通知 REAPER 更新原生试听素材，加载/停止该素材，等待预览读回就绪，再恢复全长、定位并调用原生“从上次定位位置播放”。不通过 `OpenMediaExplorer(path)` 加载点击素材，避免该 API 改变当前库/目录/搜索视图。

行信息在点击时重新解析，包括素材库隐藏的完整路径；等待期间如果行、目录或选择改变则取消。拖拽、关闭、关掉缩略图、刷新缓存同样取消待处理请求。该流程不增加磁盘波形缓存，不运行独立播放器。

诊断字段：`seek_requests`、`seek_completed`、`seek_cancelled`、`seek_pending`、`seek_ratio`、`seek_path`、`seek_error`。`seek_completed` 表示已向原生控件发出定位和播放命令，不表示已验证实际声卡输出。
