# Media Explorer 波形缩略图 v0.4.3

新增实时波形颜色设置，各平台插件版本统一为 0.4.3。

## 使用新功能

在主动作列表搜索 **Customize waveform colors**，执行 `Media Explorer: Customize waveform colors...`，也可为它分配快捷键或工具栏按钮。

- 支持取色区域、色相条、常用色和 HEX 输入；面板示例及列表波形实时更新。
- 普通和选中波形可分别配色；默认选中颜色继续跟随主题。
- Save 通过 REAPER GetExtState/SetExtState 持久保存，重启保留；Cancel、Esc 或关闭窗口撤回未保存修改。
- Reset all 预览恢复默认，再点 Save 保存；无效 HEX 不允许保存。
- 改色只更新绘图缓存，不重新读取音频或 reapeaks。

配置位于 `MediaWaveThumbnails` section 的 `color_normal` / `color_selected`，使用标准 `#RRGGBB`，空值表示默认。

## 下载与安装

选择对应平台 ZIP：Windows x64、macOS arm64（Apple Silicon）、macOS x86_64（Intel）、Linux x86_64。每个包附有安装说明，SHA256SUMS.txt 用于校验。Source code 为源码包。

1. 在 REAPER 的 Options 菜单中打开 Show REAPER resource path in explorer/finder，找到资源目录。
2. 正常退出 REAPER。
3. 把 ZIP 内 UserPlugins 中的插件复制到资源目录的 UserPlugins，替换同名旧文件。
4. 重启 REAPER。

## 验证

Windows REAPER 7.84 已通过实时调色、保存/取消/重置、真正退出重启后恢复，以及原有波形与点击试听回归。Mac arm64/x86_64、Linux 和 Windows 的云端构建及相应模型/宿主测试全部通过。新面板的 Mac/Linux 实际交互仍需实机确认；此前 0.4.2 的用户实机反馈不作为新面板的验证记录。

Mac 产物使用 ad-hoc 签名；Linux 在 Ubuntu 22.04 构建。Windows 发布 DLL 为已实测的 MinGW 构建。
