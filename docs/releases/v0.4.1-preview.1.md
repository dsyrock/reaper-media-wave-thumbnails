# Media Explorer 波形缩略图 v0.4.1-preview.1

首次公开预发布。在 REAPER 原生 Media Explorer 的详细列表中增加 Waveform 列，无需逐个点击素材即可查看波形。

## 本次修复

- 防止浏览目录时自动打开 MusicXML、MIDI、工程和文本文件，避免缩略图功能触发乐谱导入及异常 XML 的错误弹窗。
- 修复旧版 Linux SWELL 缺少表头查询接口时反复创建 Waveform 列的问题，兼容性回归覆盖 REAPER 6.83 对应的缺失接口场景。
- 无法确认原生列布局时暂停处理，避免反复补列。

## 安装与更新

1. 正常退出 REAPER。
2. 在 REAPER 的 Options 菜单中使用“Show REAPER resource path in explorer/finder”找到资源目录。
3. 将 ZIP 内 `UserPlugins` 中的插件复制到该资源目录的 `UserPlugins`，更新时替换同名旧文件。
4. 重启 REAPER，打开 Media Explorer 并使用详细列表视图。

主动作列表搜索 `waveform thumbnails`，可开关波形列或刷新缓存。卸载时退出 REAPER 后删除对应插件文件。旧版已经增加的临时列会随窗口销毁清除，更新前务必退出 REAPER。

## 验证与限制

- Windows 发布 DLL 使用 MinGW-w64 GCC 15.2 构建，已在 Windows REAPER 6.83/7.84 的独立环境中通过两个报告 XML 样本及原有波形/缓存/列开关回归。
- Mac arm64/x86_64 编译、核心测试、架构/入口校验及 ad-hoc 签名通过；未做 Apple Developer ID 签名或公证，尚未在 Mac REAPER 中运行验证。
- Linux 使用 Ubuntu 22.04/GCC 11.4.0 构建，核心测试、新旧 SWELL 模拟宿主测试、ELF/入口/依赖检查通过；真实 Linux REAPER 6.83 界面仍需实机复测。较老发行版可能需要自行重新构建。
- 不增加磁盘缩略图库，继续复用已有 reapeaks；峰值保留在本次运行的内存中，重启后仍需重新读取峰值及生成位图。
