# Media Explorer 波形缩略图 v0.4.2

正式发布，Windows、macOS、Linux 插件内部版本统一为 **0.4.2**。

## 新功能与修复

- 点击 Waveform 缩略图的相对位置，从对应位置进行原生试听；播放过程中再次点击可以跳转。
- 连续快速点击以最后一次待处理请求为准；拖拽、修饰键选择和选择变化会取消对应请求。
- 波形双击用于试听定位，不向工程插入素材；文件名等原生区域继续保持 REAPER 行为。
- 保留此前的 MusicXML/MIDI 排除、旧 Linux SWELL 重复建列修复及列布局保护。

点击定位时，下方原生预览会恢复为全长显示。音量、路由、变速和循环继续遵循 Media Explorer 设置，不增加磁盘波形缓存。

## 安装与更新

1. 在 REAPER 的 Options 菜单中打开“Show REAPER resource path in explorer/finder”，找到资源目录。
2. 正常退出 REAPER。
3. 将 ZIP 内 `UserPlugins` 中的插件复制到资源目录的 `UserPlugins`，替换同名旧文件。
4. 重启 REAPER，打开 Media Explorer 并使用详细列表视图，点击波形对应位置即可试听。

动作列表搜索 `waveform thumbnails` 可开关波形列、刷新缓存。卸载时正常退出 REAPER 后删除对应插件文件。
